Estás abriendo el portal como archivo local (file://). Las herramientas funcionan igual, pero el navegador bloquea la memoria del tablero de observaciones, así que vas a tener que adjuntar el Excel cada vez. Para evitarlo, publicá la carpeta (GitHub Pages) o serví el portal con python -m http.server 8000.

Cómo se usa

  • Entrá a la herramienta que necesites y cargá el Excel correspondiente. Observaciones lee la hoja Listado de OS y condiciones; Capacitaciones lee la hoja base1.
  • El estado que ves en cada tarjeta se actualiza solo, con los últimos datos que cargaste en esa herramienta.
  • Desde adentro de cada tablero volvés acá con el botón ← Portal arriba a la izquierda.
  • Ningún archivo sale de tu equipo: todo el procesamiento ocurre en el navegador.
